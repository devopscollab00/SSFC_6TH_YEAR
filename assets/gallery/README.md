# Gallery Images

Add your gallery images here with the following naming format:

- `1.jpg` - Gallery image 1
- `2.jpg` - Gallery image 2
- `3.jpg` - Gallery image 3
- `4.jpg` - Gallery image 4
- `5.jpg` - Gallery image 5
- `6.jpg` - Gallery image 6

**Recommended Image Specifications:**
- Format: JPG, PNG, or WebP
- Aspect Ratio: Square (1:1) for best display
- Resolution: 800x800px or higher
- Size: Optimized under 500KB each

**How to Replace Images:**
1. Simply delete the old image file
2. Add your new image with the same name (e.g., `1.jpg`)
3. The website will automatically load the new image

**Mobile Optimization:**
The gallery uses responsive sizing, so your images will automatically scale to fit all devices.
