# Logo Files

This folder contains the church logo used throughout the website.

**Files:**
- `logo.png` - Primary church logo (used in navbar, hero, footer)

**Recommended Specifications for Logo:**
- Format: PNG (with transparent background preferred)
- Resolution: 200x200px or higher
- Size: Under 100KB
- Background: Transparent for versatility

**How to Replace:**
1. Prepare your new logo image
2. Name it `logo.png`
3. Upload/copy it to this folder
4. The website will automatically use the new logo in all locations

**Logo Placement:**
- Navigation Bar (height: 45px)
- Hero Section (height: 100px)
- Footer (height: 45px)

All placements automatically scale based on the responsive design.
